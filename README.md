# AUDC VoIP Console — מערכת טלפוניה רב-ערוצית

פלטפורמת VoIP בסגנון קונסול קשר מטוס–מגדל פיקוח (ATC): השתתפות בכמה ועידות/שיחות במקביל, שמיעה של כולן בו-זמנית, ושידור PTT לכל ערוץ בנפרד או לכולם יחד.

## הרצה

```bash
npm install
node server.js
```

ואז לפתוח בדפדפן (Chrome/Edge): **http://localhost:3000**

- כמה משתמשים על אותו מחשב — פתחו כמה טאבים.
- ברשת מקומית — גלשו ל-`http://<IP-של-השרת>:3000` (לקבלת מיקרופון על HTTP שאינו localhost השתמשו ב-ngrok: `ngrok http 3000`).
- פורט אחר: `PORT=4000 node server.js`

## יכולות

| יכולת | איך |
|---|---|
| ריבוי ערוצים במקביל | הצטרפו לכמה ערוצים — שומעים את כולם יחד |
| PTT לכל ערוץ | לחיצה ממושכת על כפתור PTT בכרטיס, או מקשים `1`–`9` |
| PTT לכל הערוצים | כפתור השידור בתחתית או מקש `SPACE` |
| VOX | כפתור VOX — דיבור משדר אוטומטית (רגישות בהגדרות) |
| עוצמה / השתקה לכל ערוץ | סליידר + כפתור השתק בכל כרטיס, ו-Master בתחתית |
| פאן סטריאו לכל ערוץ | סליידר PAN — מיקום הערוץ ימין/שמאל (דאבל-קליק לאיפוס) |
| הקלטת ערוץ | כפתור ● הקלט — נשמר כקובץ webm להורדה |
| שיחות פרטיות 1:1 | כפתור 📞 ליד מפעיל ברשימת המחוברים |
| חייגן + DTMF | כפתור "חייגן" — צלילי DTMF אמיתיים בשיחה פעילה |
| חיבור למרכזיה (SIP) | בחייגן — חיבור ל-PBX ארגוני (Asterisk/FreePBX) דרך WebSocket SIP |
| בחירת התקני שמע | ⚙ הגדרות — מיקרופון והתקן השמעה |
| סימולציית דמו | כפתור "סימולציה" — מפעילים וירטואליים בכל הערוצים |
| ערוצים דינמיים | "＋ ערוץ חדש" — משותף לכל המשתמשים המחוברים |

## ארכיטקטורה

- **server.js** — Node.js + Express + Socket.io: signaling ל-WebRTC (offer/answer/ICE), ניהול ערוצים ורשימת מחוברים, ממסר PTT ושיחות פרטיות.
- **public/** — לקוח: WebRTC mesh לכל ערוץ; Web Audio API לניתוב — מיקרופון → GainNode לכל ערוץ (PTT), נכנס → bus ערוץ → Panner → Master. ההקלטה, הסימולציה והעוצמות כולן עוברות דרך אותו גרף שמע.

## API

`GET /api/channels` — רשימת ערוצים + מי מחובר לכל אחד.
